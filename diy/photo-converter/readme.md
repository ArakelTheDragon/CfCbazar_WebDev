# CfCbazar Photo Converter Tool

A fast and lightweight browser‑based photo converter that supports **PNG**, **JPG**, and **WEBP** formats.  
Built for the CfCbazar DIY ecosystem and available online at:  
**https://cfcbazar.42web.io/diy/photo-converter/**

Source code:  
**https://github.com/ArakelTheDragon/CfCbazar_WebDev/tree/main/diy/photo-converter**

---

## ✨ Features

- Convert images between **PNG → JPG → WEBP**  
- Simple drag‑and‑drop or file‑select interface  
- Instant conversion directly in the browser  
- No upload required — everything runs client‑side  
- Clean CfCbazar UI using global `/css/styles.css`  
- Mobile‑friendly layout  
- Download button for the converted file  
- Supports transparency when converting PNG ↔ WEBP  

---

## 📁 File Structure

```
/diy/photo-converter/
│── index.php        # Main converter interface
│── converter.js     # Handles image conversion logic
│── styles.css       # CfCbazar global styling
```

---

## ⚙️ How It Works

### 1. Upload an Image  
Choose a PNG, JPG, or WEBP file.

### 2. Select Output Format  
Pick the format you want to convert to.

### 3. Convert & Download  
The tool processes the image instantly and provides a download link.

All conversions happen **locally in your browser**, ensuring privacy and speed.

---

## 🔒 Privacy & Security

- Images are **not uploaded** to any server  
- Conversion happens entirely in the browser  
- No data is stored or transmitted  
- Safe for personal and sensitive images
