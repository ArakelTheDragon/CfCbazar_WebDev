# 🎮 CfCbazar Games

Welcome to the **CfCbazar Games** repository. This collection contains free browser-based games built with **HTML, CSS, JavaScript, and PHP**, designed to run directly in a web browser with no installation required.

The goal of this project is to provide lightweight, fun, and educational games that integrate with the **CfCbazar** and **WorkToken** ecosystem.

---

## Features

- 🎮 Free browser games
- 📱 Mobile-friendly design
- ⚡ Fast loading
- 🧩 Simple and lightweight code
- 🔒 Secure PHP backend where required
- 💰 Ready for WorkToken integration
- 🛠 Easy to extend with new games

- PHP 8.2+
- MySQL / MariaDB
- Modern web browser

## Installation

Clone the repository:

```bash
git clone https://github.com/ArakelTheDragon/CfCbazar_WebDev.git
```

Copy the project to your web server and configure your database settings in:

```
config.php
```

---

## Development

New games can be added by creating a new folder inside the `games` directory and linking it from `games/index.php`.

The project uses shared functionality from:

- `/includes/reusable.php`
- `/css/styles.css`
- `/js/scripts.js`

to maintain a consistent look and reduce duplicated code.
